読み上げ

投稿を声にする

基本
  • テキスト読み上げ 投稿を順に再生・キュー管理
  • 辞書 特殊読み・ユーザー辞書・GIF・登録wav
  • 話者クローン 参照音声31本から選ぶ
  • エンジン多重化 speech.cpp / Irodori / VOICEVOX を切替
  • 自動フォールバック 落ちたら次のエンジンへ・復帰も自動
  • 速度・音量 話者ごとに設定

声まわり（実験）

VCの中を扱う

実験
  • 空気読み 喋っている間だけ音量を下げる（音量カーブ）
  • 聞き取りタブ 空気読みの様子を1秒ごとに表示
  • 音量カーブ編集 区間ごとの音量点をドラッグで調整
  • 発話検知 音声パケットの到着だけで判定（デコード無し）
  • 入室案内 同じ人・同じ話者なら声を使い回す

画像

引用画像と生成

miq
  • miq 引用画像 返信 + 「miq」で生成
  • 構図4種 classic / mirrored / magazine / literary（autoでランダム）
  • 長文も比率固定 縦に伸ばさず、文字を縮めて収める
  • 多言語 アラビア語・ヘブライ語などの文字組み
  • 絵文字 色つき・サーバー絵文字・欧文は斜体
  • メンション名 <@123> をそのサーバーの表示名に
  • 画像生成 /imggen（anima の起動・停止）

翻訳・会話

言葉をまたぐ

LLM
  • 翻訳 チャンネルごとに対象を設定
  • バックエンド選択 Sarashina（クラウド）/ ローカルLLM / atmos（z170）。/llm switch で切替
  • 会話モード ボットが会話に参加
  • 要約 流れをまとめる
  • Webチャット ダッシュボードから対話

止めない・戻せる

この実験場について

  • Discordの読み上げと同じ規約で鳴ります。辞書に登録した音声もそのまま使えます。
  • 鳴らした音は保存しません。ページを閉じれば消えます。
  • 誰でも使えるため回数を制限しています（同じ人で1分8回まで）。
  • 文章は300文字まで。効果は40区間まで。
