# 明示台帳方式の限定的な再帰スナップショット

**本番切替の準備完了を保証するツールではありません。** 実運用前に合成データと隔離環境で手順を検証してください。既存の offline_snapshot.py と独立した機能です。指定したディレクトリ以下の隠しファイルと空ディレクトリを含む全要素を、事前に人間が作成した台帳と完全一致させてから新規ディレクトリにコピーし、検証、別の新規ディレクトリへ元の階層で復元します。アプリ固有の変換や書込後の旧形式への逆変換は行いません。

## 絶対条件と制限

- **旧 Bot、export timer、全サービス・全 writer を止め、停止を実行者が確認し、全操作完了まで再開しない。** このツールは停止、単一 writer、ファイル間の同時点整合性を保証できません。停止を確認できなければ使わないでください。
- 台帳の正確さは運用者の責任です。ファイルの型・業務意味・DB 種別・必要なデータが入力ツリーの外にないかは自動判定しません。各 SQLite は必ず sqlite として指定し、暗号化 DB、壊れた DB、アプリ固有形式や非標準形式など不明なものを通常ファイルに分類してはいけません。通常ファイルに SQLite ヘッダーがあれば拒否しますが、これは型の完全判定ではありません。
- シンボリックリンク、ハードリンク、特殊ファイル、名前が -wal / -shm / -journal で終わるファイルは、空でもすべて拒否します。SHM や非空 WAL での復旧・処理は対応しません。消去を指示するものではありません。安全な別途手順を検討してください。元データは SQLite で開かず、コピー上で SQLite backup と integrity_check / foreign_key_check を実行します。
- 秘密を含むすべての対象がコピーされます。出力を暗号化しません。台帳の秘密や出力先への複製が適切か運用者が判断し、保管・暗号化・廃棄を管理します。出力・親は他ユーザーからアクセス不能、出力ディレクトリとファイルはそれぞれ 0700 / 0600。元の権限、所有者、タイムスタンプ、ACL、拡張属性は保持しません。
- 人間の確認とファイルのハッシュ・再走査は、同時変更を完全に排除するものではありません。攻撃者や同一ユーザーの他プロセスが操作できず、入力や出力へ別の場所を重ねる bind mount がない、信頼済みホスト上で実行してください。電源断に対する耐久性は保証しません。強制終了で残った出力は .incomplete で識別・隔離し、未使用の別名でやり直してください。
- ハッシュは偶発的破損の検出で、マニフェストとデータ双方の改ざん防止にはなりません。検証は業務上の正しさ、旧アプリとの互換性、外部データの網羅性を保証しません。実データの取扱いおよび切替判断は運用者の責任です。

## 台帳の形式

停止確認後、次のコマンドで対象ツリー外の新規ファイルにレビュー用台帳を生成できます。出力親は実行者所有かつ 0700、台帳は 0600 です。既存ファイルは上書きしません。ツリーを読み取り専用で走査し、各ディレクトリとファイルを列挙します。リンク・特殊ファイル・SQLite 補助ファイルは従来どおり拒否します。

   python3 tools/tree_snapshot.py inventory /private/input /private/inventory.json --offline-confirmed

**全ファイルは SQLite も含めて unreviewed と記載されます。** 内容を開いて種別を自動判定しません。運用者は各ファイルの種類と必要性を確認して、すべての unreviewed を正しい sqlite または file に書き換えてください。分類できないファイルがあれば作成しないでください。未分類が一つでもあれば create は拒否します。生成は走査時点の一覧であり、writer 停止、内容の一貫性や完全性を保証しません。

**台帳自体に機密情報を含むファイル名・ディレクトリ名が入る場合があります。** 内容は標準出力に表示しませんが、台帳の保存・閲覧・編集・共有・廃棄も秘密として管理してください。入力ツリーには台帳を置かず、編集時のエディタの一時ファイル・バックアップや同期先にも注意してください。

手動で用意する場合も、対象ツリー外に作り、各ディレクトリも含め、ツリー直下からの相対パスを一度ずつ列挙します。例（仮の合成名）：

```json
{
  "version": 1,
  "entries": [
    {"path": "sessions", "kind": "dir"},
    {"path": "sessions/empty", "kind": "dir"},
    {"path": "sessions/sample.db", "kind": "sqlite"},
    {"path": ".hidden", "kind": "dir"},
    {"path": ".hidden/example.json", "kind": "file"}
  ]
}
```

パス区切りは /、絶対パス・..・重複・親ディレクトリ欠落は拒否。ルート名 .incomplete は予約済み。台帳に記載のない要素、または記載されているが存在しない要素が一つでもあれば中止します。

## 手順例

1. 関連サービス・タイマー・全 writer を止めて OS・サービス管理側で停止を確認し、台帳を生成するか手動作成する。全ファイルの種類を確認・分類し、正しい完全な台帳にする。
2. 入力や台帳を変更しない新規出力を作る。出力親は実行ユーザー所有で他ユーザーがアクセス不能のディレクトリにする。

   python3 tools/tree_snapshot.py create /private/input /private/snapshot --inventory /private/inventory.json --offline-confirmed

3. python3 tools/tree_snapshot.py verify /private/snapshot を実行し、成功を確認する。
4. 停止状態を維持したまま別の未存在ディレクトリへ復元する。

   python3 tools/tree_snapshot.py restore /private/snapshot /private/restored --offline-confirmed

5. 復元結果を隔離環境でアプリ固有の検査にかける。旧形式の同名ファイル・階層を再構成するだけで、旧アプリ互換性や旧データへの逆変換は別途検証が必要。
